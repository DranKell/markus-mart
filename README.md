# ⛰️ Маркус-март — Dark Outdoor Edition

Интернет-магазин аксессуаров и снаряжения для туризма и активного отдыха. Тёмная тема в спортивном outdoor-стиле, адаптивный интерфейс, корзина с бронированием и панель управления.

---

## 🎨 Особенности проекта

- **Современный тёмный UI** — глубокая slate-палитра, контрастные оранжевые акценты, неоновые glow-эффекты
- **Шрифт Oswald & Inter** — динамичные спортивные заголовки и читаемый контент
- **Каталог товаров** — подробный просмотр, галерея фотографий, цены и статус наличия
- **Корзина и оформление заявок** — удобная форма бронирования и отправки контактов
- **Панель администратора (`/admin`)** — добавление/редактирование товаров, загрузка фото, список броней и клиентов
- **Безопасность** — защита админ-панели от брутфорса (ограничение попыток, блокировка по IP)
- **Почтовые оповещения** — отправка информации о заказах через SMTP

## 🚀 Быстрый старт

### Вариант 1. Автоматический запуск (Windows)

Дважды кликните по файлу **`start.bat`**.  
Скрипт сам создаст виртуальное окружение, установит все библиотеки из `requirements.txt` и запустит сайт в браузере.

---

### Вариант 2. Ручной запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/DranKell/markus-mart.git
   cd markus-mart
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux / macOS:
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   Скопируйте пример файла конфигурации:
   ```bash
   copy .env.example .env
   ```
   *(или `cp .env.example .env` в Linux/macOS)*

5. **Запустите сервер:**
   ```bash
   python app.py
   ```

6. **Откройте сайт:**
   Перейдите в браузере по адресу: [http://127.0.0.1:5000](http://127.0.0.1:5000)
