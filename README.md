# ⛰️ Маркус-март — Экстренные расходники для туристов (Outdoor Edition)

> **Концепция:** мини-магазин товаров и расходников, которые **постоянно теряются или ломаются на сплавах и в походах**: скобы (хомуты) для рамы катамарана 40 мм, штормовые колышки для палатки, ремнаборы для сломанных дуг, фастексы и клапаны надувных баллонов.

🌐 **Онлайн-витрина (GitHub Pages):** [https://drankell.github.io/markus-mart/](https://drankell.github.io/markus-mart/)

---

## 🎨 Особенности и возможности

- **Тематический каталог «Потеряшки и расходники»** — хомуты 40 мм (с реальными фото в галерее), колышки Y-Beam, винтовые якоря, ремнаборы для дуг и ткани ПВХ, фастексы.
- **Вход в админку по паролю** — защищённый доступ к панели управления как на сервере Flask, так и в онлайн-версии на GitHub Pages.
- **Полноценный дашборд заказов** — просмотр всех заявок покупателей, смена статусов («Новый», «В работе», «Выполнен»), контакты клиентов и примечания к заказам.
- **Управление складом** — переключение статуса «В наличии / Под заказ» и изменение остатка.
- **Интерактивные модалки** — подробная карточка товара с фотогалереей и Zoom, форма онлайн-бронирования с маской телефона `+7 (...)`.
- **Переключение тем** — тёмная (Dark Slate с оранжевым неоновым акцентом) и светлая тема с сохранением выбора.

## 🚀 Быстрый запуск

### Вариант 1. Онлайн без установки
Просто откройте ссылку в браузере с компьютера или телефона:  
👉 **[https://drankell.github.io/markus-mart/](https://drankell.github.io/markus-mart/)**

### Вариант 2. Запуск локального сервера (Windows)
Дважды кликните по файлу **`start.bat`**. Скрипт создаст виртуальное окружение, установит зависимости и откроет сайт в браузере.

### Вариант 3. Ручной запуск Python Flask
```bash
git clone https://github.com/DranKell/markus-mart.git
cd markus-mart

# Создание и активация venv
python -m venv venv
venv\Scripts\activate  # В Linux/macOS: source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Настройка .env (при необходимости)
copy .env.example .env

# Запуск приложения
python app.py
```
Откройте в браузере: **http://127.0.0.1:5000**

## 🔐 Доступ в админ-панель

- **Кнопка в шапке сайта:** `🔐 Вход в админку`
- **Прямой URL (для сервера Flask):** `http://127.0.0.1:5000/admin`
- **Логин:** `admin`
- **Пароль:** настраивается администратором (в файле `.env`)
- **Защита:** ограничение числа неверных попыток ввода пароля с автоблокировкой IP.

## 📁 Структура репозитория

```text
markus-mart/
├── app.py              # Flask приложение (маршруты, SQLite, защита)
├── requirements.txt    # Зависимости Python (Flask, Werkzeug, python-dotenv)
├── start.bat           # Скрипт быстрого запуска для Windows
├── .env.example        # Шаблон конфигурации
├── docs/               # Статическая сборка для GitHub Pages
│   ├── index.html      # Витрина с защищенной паролем админкой
│   └── static/         # Стили, JS и фотографии хомутов
├── static/             # Статика для сервера Flask (CSS, JS, uploads)
├── templates/          # Jinja2 шаблоны Flask (каталог, админка, вход)
└── fotos/              # Исходные фотографии товаров и логотипы
```
